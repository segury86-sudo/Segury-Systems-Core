## 📖 Descripción

**Segury-Systems-Core** es un sistema integrado que reúne el Núcleo Segury 3 y el Wantan Kernel en una sola plataforma unificada. Diseñado para gestionar servicios, automatizar tareas, monitorear seguridad y facilitar el desarrollo de proyectos tecnológicos.

Este repositorio contiene la versión completa del sistema, incluyendo todos los módulos, bots, scripts de seguridad, archivos de configuración y documentación.
